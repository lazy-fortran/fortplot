# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses date-based versioning (`YYYY.MM.PATCH`).

## 2026.11.0 (2026-11-14)

- Matplotlib-style plotting from Fortran with self-contained PNG, PDF, SVG and
  ASCII backends: line, scatter, contour, pcolormesh, bar, histogram, error
  bar, subplot and 3D plots, Unicode and mathtext labels, and animations.
- Citation metadata and one documentation tree.
